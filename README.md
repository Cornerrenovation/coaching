# Corner — coaching

Password-protected feedback-loop pages for the Corner design team, generated
from the private `cornerrenovation-core` repo by the `designer-feedback-loop`
skill. One folder per designer.

Each page is AES-256-GCM encrypted (PBKDF2-SHA256, 600k iterations) and
decrypted in the browser. This repo holds ciphertext only; the password is
shared separately, never committed. `noindex` + `robots.txt` keep it out of
search.
